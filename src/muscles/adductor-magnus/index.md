The **adductor magnus** forms the bulk of the inner thigh. Its wide fibers
run from the {{ linkicon('pelvis') }} to the {{ linkicon('femur') }}, working
with {{ link('adductor-longus') }} and {{ link('adductor-brevis') }} to draw
the leg inward.
