This book was created with the help of artificial intelligence (AI) to make
writing clearer and save time on research. I enjoy using automation and support
using AI responsibly. I also work to learn about the risks of depending too much
on it.

AI is a computer program that predicts things like text and images based on
large amounts of data. However, it may treat common information as facts, which
can lead to mistakes. There can also be errors in algorithms.

To use AI responsibly and ethically, I follow these rules:

* Always label content made by AI using 🤖.
* Always label AI content that has been checked by a person using 🧑.
* Original writing doesn't have any icons.

## Icons
