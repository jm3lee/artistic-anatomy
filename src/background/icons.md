This book is for artists, and naturally, we use icons! See below for what each
icon means. Every time you encounter an icon, it will link back to this page for
reference.

| Icon       | Meaning                                                                                                                 |
| ---------- | ----------------------------------------------------------------------------------------------------------------------- |
| :muscle:         | Notes on a muscle                                                                                                       |
| :bone:         | Notes on a bone                                                                                                         |
| :star:          | Notes a bony landmark                                                                                                   |
| :link:         | Notes on a tendon or ligament                                                                                           |
| :closed_book:         | Notes on a book                                                                                                         |
| :framed_picture:         | Artwork                                                                                                                 |
| :construction:         | Under a HEAVY construction. Unlikely to be useful without further work.                                                 |
| :robot:         | AI Generated. See [Responsible Use of AI](responsible-use-of-ai.html).                                                  |
| :man:         | AI Generated, Human Verified. See [Responsible Use of AI](responsible-use-of-ai.html).                                  |
